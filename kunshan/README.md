# 坤山建設 · 竹北建案地圖

坤山機構在竹北市的 20 個住宅建案（18 個已完工、2 個預售），以 Leaflet + OpenStreetMap 呈現。
點標籤看基本資料、最近一筆實價登錄與目前在售物件（15 戶，分布在 11 個建案）。

## 檔案
- `index.html`、`app.js`、`styles.css`、`data.js`：網站本體（`python3 -m http.server 8767` 即可）
- `standalone.html`：全部內嵌（只有 Leaflet 走 CDN），可直接從 `file://` 開啟
- `screenshot.png`（桌機，坤山一景彈窗）、`screenshot-mobile.png`（手機 390×844）、`screenshot-mobile-popup.png`
- `_build/`：`build_data.py`（CSV → data.js）、`standalone.py`、`geo.py` / `geo.json`（座標查核）、`test/`（headless Chrome 測試）

## 功能
- 標籤顏色依完工年代：灰＝2010 前、藍＝2010–2017、綠＝2018 後、紫＝預售；紅色「售N」＝在售戶數；坤德知之加星號。
- 縮放 ≥15 顯示全名，≥16 加上單價；標籤重疊時，次要的會縮成小圓點（數字＝在售戶數）。
- 側欄（手機為可上拉的底部清單）：排序（完工年／單價／有待售）、篩選（區域、只看有待售、只看 4,000 萬以下待售、室內 ≥32 坪）、點清單飛到標記。
- 「在售物件」分頁：15 戶依總價等排序；總價 ≤4,000 萬且室內 ≥32 坪者綠底標示。

## 資料定義
- 單價＝（總價−車位價）÷（權狀坪−車位坪）；車位價未分列時每個以 120 萬推估。
- 室內＝主建物＋附屬建物（含陽台），依實價登錄；在售物件多以同社區同主建物坪數的成交推估。請以謄本核對。
- 來源：坤山官網業績、內政部實價登錄 101S4–115S3、591、信義；樂居被 Cloudflare 擋住。
