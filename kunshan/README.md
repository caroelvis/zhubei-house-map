# 竹北建商建案地圖 · 坤山／德鑫／椰林

五家建商在竹北市的住宅建案共 124 案（坤山 20、德鑫 24、椰林 49、惠宇 5、富宇 26），在售 127 戶（坤山 15、德鑫 30、椰林 29、惠宇 7、富宇 46）。Leaflet + OpenStreetMap。

## 檔案
- `index.html`、`app.js`、`styles.css`、`data.js`：網站本體（`python3 -m http.server` 即可）
- `standalone.html`：全部內嵌（只有 Leaflet 走 CDN），可直接從 `file://` 開啟
- `screenshot.png`（桌機）、`screenshot-mobile.png`（390×844）、`screenshot-mobile-listings.png`
- `_build/`：`build_data.py`（CSV → data.js）、`standalone.py`、`geo.json`（座標＋OSM 反查）、`test/b.js`（headless Chrome 測試）
- 原始資料：`/workspace/builders-zhubei/`（dexin/yelin-projects.csv、-listings.csv、SUMMARY.md）、`/workspace/kunshan-zhubei/`

## 功能
- 上方建商分頁：全部／坤山／德鑫／椰林；地圖、清單、篩選、在售物件都跟著切換。
- 標籤：左側「坤／德／椰」字樣＋外框＝建商（坤＝棕色圓角、德＝紅色方角、椰＝綠色膠囊形）；底色＝完工年代（灰 2010 前、藍 2010–2017、綠 2018 後、紫 預售）；紅色「售N」＝在售戶數。
- 篩選：區域、只看有待售、只看 4,000 萬以下待售、室內 ≥32 坪。總價 ≤4,000 萬且室內 ≥32 坪的物件綠底標示。
