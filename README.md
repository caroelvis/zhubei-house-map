# 竹北待售＋預售地圖 · 3,000–4,500 萬 · 主+附 ≥ 32 坪

樂居（leju.com.tw）2026-10-04/05 掃描之竹北待售物件 160 筆（已去重），依建案／社區分組的 Leaflet 互動地圖。

另疊加 **預售圖層**（2026-10-06 加入）：2026 年開賣之竹北預售建案 15 案（內政部實價登錄 11 案＋已開賣未實登 4 案）、主要候選 **坤德知之**（★，數字皆為推估），以及 2025 年底開賣／舊案 6 案（參考）；另有預設隱藏的「樂居其他新案」20 案。

## 開啟方式
- **雙擊 `standalone.html`**：單一檔案，資料／CSS／JS 皆內嵌（Leaflet 與 OSM 圖磚需連網）。
- 或本機伺服器：`python3 -m http.server 8766` → <http://127.0.0.1:8766/>（`index.html` + `data.js` + `app.js` + `styles.css`）。
- 深層連結：`index.html#c=豐邑明日軸` 直接開啟該社區。

## 功能
- 每個建案／社區一個價格標籤（同社區各戶平均座標），標示「社區名 最低–最高萬」；綠＝全部 < 4,000 萬、橘＝全部 ≥ 4,000 萬、綠橘＝兩者皆有。縮放 < 15 只顯示價格，重疊的標籤自動縮為小圓點。
- 點標籤 → 彈窗：粉紅「在樂居開啟」按鈕（樂居社區頁；無社區頁者開最低價物件），下方各戶總價／主+附／主建物／權狀／樓層／房／屋齡／單坪，點任一列開啟該物件樂居頁。
- 側欄：社區名本身即樂居連結；排序（總價、主+附、屋齡、單坪價＝總價÷主+附）；篩選（區域、型態、總價區間、主+附下限、屋齡上限、關鍵字、只看 4,000 萬以下、只看莊敬南路以東光明六路以南、隱藏辦公室／疑似非住宅／資料存疑）。
- 莊敬南路／光明六路界線（OSM 中心線虛線、延伸線點線），可切換。

## 預售圖層
- 側欄最上方圖層開關：「顯示待售」「顯示預售」（預設皆開）、「樂居其他新案」（預設關）。標題列分別顯示待售／預售數量。
- 標記：紫色「預售」價格標籤＝有實價登錄（單價範圍 萬/坪・總價範圍）；白底紫虛線＝尚無實登，顯示「開價」或「推估」；金框 ★＝坤德知之（不會被縮成圓點）；藍灰「新案」＝樂居其他新案。
- 彈窗：「在樂居開啟」（樂居查無此案者改為橘色「改開 591」按鈕並標示）、建商、單價範圍與中位數、總價範圍（含車位）、車位價、格局／坪數、主+附估算上限、成交筆數與交易期間、預計完工、主建物 > 30 坪判斷、4,000 萬高價住宅門檻（新竹縣：貸款上限 3 成、無寬限期）。坤德知之另附 A／B／C 戶型表（權狀／主建物／陽台／室內／推估總價）。
- 篩選套用方式：區域、型態、關鍵字、東南側（同一條莊敬南路／光明六路界線判定）照常套用；總價以「總價區間是否重疊」判斷，滑桿在最左／最右端視為不設限，總價未知者不篩；主+附下限在最小值（32）時不篩預售，調高後只篩有估算值者（權狀×(1−公設比) 上限，或坤德知之室內坪數）；「只看 4,000 萬以下」以最低總價判斷；屋齡、資料存疑旗標不適用於預售。
- 排序：總價／主+附依上述對應值插入列表；單坪價定義不同（預售為權狀、不含車位），預售排在最後。

### 預售資料來源
- `/workspace/zhubei-presale-2026.json`（內政部實價登錄預售屋 111S3–115S3＋2026-10-01 本期，交易日最晚 2026-08-20；單價 =（總價−車位價）÷（權狀−車位面積），已排除解約、親友／特殊交易）。開價取自 591／樂居。
- 坤德知之：使用者提供之戶型面積（A 54.52／B 48.70／C 45.18 權狀坪）、推估單價 84–88 萬/坪（不含車位）、車位 B1 約 270／B2 約 260／B3 約 240 萬、總價約 4,000–5,300 萬；A 戶含車位約 4,720／4,940／5,160 萬。B、C 戶總價為以 84–88 萬＋車位 240–270 萬自行推算。全部為推估。
- 樂居連結與座標：先從樂居地圖 API（`community_map/object/mapRadiusData`）掃描竹北社區，再逐一抓取 `www.leju.com.tw/community/<id>` 驗證頁面標題，座標取自頁面內嵌座標。家興大苑、鴻柏鴻湛、IKIGAI 在樂居查無頁面，改連 591（新建案頁或實價登錄社區頁），座標取自 591 頁內嵌座標。所有點皆經 OSM Nominatim 反查確認位於新竹縣竹北市。
- 樂居其他新案：樂居地圖標示為新案（屋齡 −1）且不在上述清單之竹北建案；價格為樂居頁標題所列（一年均價／最新價／開價，算法與實登清單不同）。
